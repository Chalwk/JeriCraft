# JERICRAFT DISCORD CATEGORY/CHANNEL STRUCTURE

---

## INFO

| Channel                              | Description                                                                                           |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `the-gatehouse` (text channel)       | Landing page. Start here for an introduction to the server and links to everything you need           |
| `the-royal-decree` (text channel)    | Rules, policies, and important information for all members.                                           |
| `arrivals-departures` (text channel) | Notifications when players join or leave the guild, marking arrivals and departures from the kingdom. |
| `introductions` (forum)              | Say hi and introduce yourself to the community.                                                       |

---

## SOCIAL

| Channel                          | Description                                                         |
| -------------------------------- | ------------------------------------------------------------------- |
| `chatter-box` (text channel)     | General discussion about JeriCraft and Minecraft.                   |
| `bards-gallery` (text channel)   | Screenshots, builds, artwork. Let your world's beauty be shown off. |
| `server-activity` (text channel) | Automatic notifications for in-game activity.                       |
| `bug-reports` (forum)            | Report bugs, glitches, or other server issues.                      |

---

## GITHUB

| Channel                           | Description                                                   |
| --------------------------------- | ------------------------------------------------------------- |
| `contributing` (forum)            | Learn about contributing to the JeriCraft site documentation. |
| `website-git-feed` (text channel) | Git notifications (pull, push, commit, etc).                  |
| `website-updates` (text channel)  | Hand-posted changelogs and announcements about the website.   |

---

## VOICE

| Channel                   | Description                                            |
| ------------------------- | ------------------------------------------------------ |
| `General` (voice channel) | Main public voice channel.                             |
| `In-Game` (voice channel) | Voice chat for players currently adventuring together. |

---

## COUNCIL CHAMBERS (hidden to the public)

| Channel                      | Description                                               |
| ---------------------------- | --------------------------------------------------------- |
| `watch-tower` (text channel) | Admin logs, moderation notes, and server oversight.       |
| `Admin Chat` (voice channel) | Private staff voice channel for discussions and planning. |

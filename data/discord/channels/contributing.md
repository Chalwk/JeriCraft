Want to help improve the JeriCraft website?

You can contribute guides, fix typos, update command lists, add shop pages, or improve existing pages.

Repository:
https://github.com/Chalwk/JeriCraft

Read the full contributing guide here:
https://github.com/Chalwk/JeriCraft/blob/main/CONTRIBUTING.md

The guide covers:
- How to submit a pull request
- Writing new guides in `_guides`
- Adding shop pages in `_shops`
- Updating existing `pages` and `includes`
- Front matter, image paths, and style conventions
- Testing your changes locally

If you have questions, ask in this forum: <#1553874602407763968>.

When you submit a pull request or push changes, our <#1553867135611179149> channel will automatically post a notification.

Thanks for helping make JeriCraft better for everyone.

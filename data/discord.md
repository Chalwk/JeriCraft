## Not in a category

| Channel                  | Description                                                                                           |
| ------------------------ | ----------------------------------------------------------------------------------------------------- |
| `the-kingdoms-chronicle` | Landing page. Start here for an introduction to the server and links to everything you need.          |
| `the-royal-decree`       | Rules, policies, and important information for all members.                                           |
| `writ-of-allegiance`     | Information about server roles, including self-assignable roles and what each role represents.        |
| `the-portcullis-gate`    | Notifications when players join or leave the guild, marking arrivals and departures from the kingdom. |

## THE HERALD'S PROCLAMATION

| Channel            | Description                                                               |
| ------------------ | ------------------------------------------------------------------------- |
| `town-bulletin`    | Community announcements, server events, and public notices.               |
| `court-council`    | Suggestions, feedback, and community discussions about the server.        |
| `merchants-stall`  | Advertise your in-game shops and browse what other players have for sale. |
| `scribes-quill`    | Guides, tutorials, and helpful resources for players.                     |
| `pardoners-appeal` | Appeals, reports, and support requests.                                   |
| `introductions`    | Introduce yourself and meet fellow adventurers.                           |

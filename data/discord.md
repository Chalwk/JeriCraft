# JERICRAFT DISCORD CATEGORY/CHANNEL STRUCTURE

---

## INFO

| Channel               | Description                                                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| `faq`                 | Landing page. Start here for an introduction to the server and links to everything you need           |
| `the-royal-decree`    | Rules, policies, and important information for all members.                                           |
| `introductions`       | Introduce yourself and meet fellow adventurers.                                                       |
| `the-portcullis-gate` | Notifications when players join or leave the guild, marking arrivals and departures from the kingdom. |

---

## SOCIAL

| Channel           | Description                                                         |
| ----------------- | ------------------------------------------------------------------- |
| `chatter-box`     | General discussion about JeriCraft and Minecraft.                   |
| `bards-gallery`   | Screenshots, builds, artwork. Let your world's beauty be shown off. |
| `server-activity` | Automatic notifications for in-game activity.                       |

---

## VOICE

| Channel   | Description                                            |
| --------- | ------------------------------------------------------ |
| `General` | Main public voice channel.                             |
| `In-Game` | Voice chat for players currently adventuring together. |

## COUNCIL CHAMBERS (hidden to the public)

| Channel       | Description                                               |
| ------------- | --------------------------------------------------------- |
| `watch-tower` | Admin logs, moderation notes, and server oversight.       |
| `In-Game`     | Private staff voice channel for discussions and planning. |

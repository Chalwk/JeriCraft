# JERICRAFT DISCORD CATEGORY/CHANNEL STRUCTURE

---

## INFO

| Channel               | Description                                                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| `the-gatehouse`       | Landing page. Start here for an introduction to the server and links to everything you need           |
| `the-royal-decree`    | Rules, policies, and important information for all members.                                           |
| `arrivals-departures` | Notifications when players join or leave the guild, marking arrivals and departures from the kingdom. |

---

## SOCIAL

| Channel           | Description                                                         |
| ----------------- | ------------------------------------------------------------------- |
| `chatter-box`     | General discussion about JeriCraft and Minecraft.                   |
| `bards-gallery`   | Screenshots, builds, artwork. Let your world's beauty be shown off. |
| `server-activity` | Automatic notifications for in-game activity.                       |
| `bug-reports`     | Report bugs, glitches, or other server issues.                      |

---

## GITHUB

| Channel            | Description                                                   |
| ------------------ | ------------------------------------------------------------- |
| `contributing`     | Learn about contributing to the JeriCraft site documentation. |
| `website-git-feed` | Git notifications (pull, push, commit, etc).                  |

---

## VOICE

| Channel   | Description                                            |
| --------- | ------------------------------------------------------ |
| `General` | Main public voice channel.                             |
| `In-Game` | Voice chat for players currently adventuring together. |

## COUNCIL CHAMBERS (hidden to the public)
